# Experiment evidence

Store each experiment's small JSON summaries and artifact manifests in a
directory matching its experiment ID. Link each build, test, benchmark and
match to exact engine commits, network hashes, executable hashes, tool
versions and run settings. Keep raw PGNs and logs with durable artifacts and
record their immutable digest, location and retention period. Never commit
credentials or engine binaries. The versioned experiment ledger links these
artifacts to the responsible roles and decision.
